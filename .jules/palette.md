## 2024-05-24 - Accessibility Enhancements in Auth Gateway\n**Learning:** Implementing accessibility (a11y) improvements like ARIA roles (role="alert") for error messages and dynamic state attributes (aria-pressed, aria-label) for interactive UI elements (like password toggles) are critical for providing a good UX to screen reader users in plain HTML/JS applications. Using pointer-events: none in conjunction with Javascript disabled state is a robust pattern to prevent double submissions.\n**Action:** Always ensure custom interactive elements have proper ARIA attributes describing their state and purpose. Incorporate role="alert" and aria-live for dynamic error displays to ensure screen readers announce them proactively.

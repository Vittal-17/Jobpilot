## 2023-10-27 - [Add Security Headers to FastAPI Backend]
**Vulnerability:** The FastAPI backend did not include standard security headers in its responses, leaving the application vulnerable to common attacks such as Clickjacking (missing X-Frame-Options), MIME type sniffing (missing X-Content-Type-Options), and potentially lacking enforced HTTPS connections (missing HSTS) and Content Security Policy (CSP).
**Learning:** When configuring Content-Security-Policy (CSP) headers in a FastAPI backend, care must be taken. Explicitly allow `script-src` and `style-src` from `cdn.jsdelivr.net`, and `img-src` from `fastapi.tiangolo.com`, otherwise the built-in interactive API documentation (/docs and /redoc) will break because it relies on those external resources.
**Prevention:** Implement a global HTTP middleware that automatically adds defense-in-depth security headers (`X-Content-Type-Options`, `X-Frame-Options`, `Strict-Transport-Security`, `Content-Security-Policy`) to every API response, carefully configuring the CSP for standard FastAPI endpoints.
